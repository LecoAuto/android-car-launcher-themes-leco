Leco Car Launcher is engineered for the modern automotive landscape. Whether your vehicle features a classic wide-screen or a contemporary Tesla-style portrait display, Leco scales perfectly.

### Why Leco stands out:
*   **🔄 Horizontal & Vertical Support:** Seamlessly adapts to both Landscape and Portrait orientations. One theme, any screen.
*   **🖼️ Native PiP Dashboard:** True multitasking. Keep your Map (Google Maps/Waze) or Music player active on the dashboard.

## 📂 Theme Project Structure

Build themes using standard Android resources for maximum performance and easy learning.

| File/Folder | Description |
| :--- | :--- |
| **`config.json`** | Core settings (Author, Version, UI behaviors). |
| **`layouts/`** | **Native Android XML** layouts (Supports adaptive H/V orientation). |
| **`icons/`** | Custom App icon packs. |
| **`images/`** | Static assets and background resources. |
| **`lotties/`** | **Lottie Animation** files for dynamic widgets. |
| **`licons/`** | Exclusive Leco system widget icons. |
